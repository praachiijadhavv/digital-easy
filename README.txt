DIGITAL EASY - INSTALLABLE APP (PWA)

Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png

1) Put ALL these files in one folder and host that folder on any HTTPS website
   (free options: Netlify Drop - app.netlify.com/drop, GitHub Pages, Cloudflare Pages).
   Installing only works over https:// (or http://localhost), not by double-clicking the file.

2) Open the website link on the phone in Chrome (Android) or Safari (iPhone).
   Android Chrome: tap "Install App" on the Home page, or the menu (3 dots) -> "Install app" / "Add to Home screen".
   iPhone Safari: Share button -> "Add to Home Screen".

3) The app now has its own icon, opens full-screen, and works offline after the first visit.
